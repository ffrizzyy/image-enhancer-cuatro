# Image Enhancer

[![CI](https://github.com/ffrizzyy/image-enhancer-cuatro/actions/workflows/ci.yml/badge.svg)](https://github.com/ffrizzyy/image-enhancer-cuatro/actions/workflows/ci.yml)

A Windows desktop app that enhances a large image by cutting it into overlapping tiles, sending each tile to an AI
provider (ChatGPT, Gemini or Grok) through that provider's website, and stitching the results back into one picture.
You log in to your own accounts; the app never reads or stores your password and never solves captchas for you.

## Highlights

- **One chat per picture.** Tiles are sent one at a time in a single provider conversation, so the picture keeps a
  consistent look instead of each tile being generated by a fresh chat.
- **Pause instead of fail.** A captcha, a logged-out session or a usage limit pauses the job and brings the provider
  window forward. Resuming continues without repeating finished tiles.
- **Crash-safe.** Jobs, tiles and attempts live in SQLite. Killing the app mid-run leaves every committed tile behind,
  and the next start queues only what is unfinished.
- **Review the result.** Compare original and enhanced at up to 400%, inspect the seams, see which tiles were flagged,
  and re-run a single tile with its own prompt or a different source picture.
- **Full-size export.** Save as PNG, JPEG or WebP. If a provider returns a larger tile than it was sent, the extra
  detail is kept (up to 4x, capped at 72 megapixels).


## Account and terms-of-service risk

Automating a provider's website may go against its terms of service. Providers can rate-limit, challenge or suspend
accounts they see as automated. You use your own accounts at your own risk. The app shows this notice on first run and
you can read it again in **Settings**. Images are sent only to the provider you choose.

## Setup

Requires Node 22 and pnpm.

```
pnpm install
pnpm dev          # build and start the app
```

Provider windows use the app's built-in browser (never your system default browser). Open **Settings**, choose
**Open login** for a provider and log in yourself.

## Commands

| Command | What it does |
|---|---|
| `pnpm dev` | Build and run the app |
| `pnpm test` | All unit, integration, accessibility and isolation tests |
| `pnpm typecheck` / `pnpm lint` | Type and lint checks |
| `pnpm build` | Build every package |
| `pnpm package` | Unpacked Windows test build in `apps/desktop/release/win-unpacked` |
| `pnpm dist` | Windows installer and portable exe in `apps/desktop/release` |
| `pnpm e2e` | Drive the real Electron window through import → setup → captcha pause → resume → export |
| `pnpm --filter @ie/desktop smoke` | Launch the built app headlessly and run an import and a fake job |

To try the whole flow without an account, run the app with the fake provider (development builds only):
`IE_FAKE_PROVIDER=1 pnpm dev`. `IE_FAKE_FAIL_RATE` (0-1) injects failures, `IE_FAKE_DELAY_MS` slows it down, and
`IE_FAKE_MODES=ok,challenge,ok,...` scripts one outcome per provider call (the e2e uses this to inject a captcha).

## Sharing the app

`pnpm dist` writes one file to `apps/desktop/release`:

- `Image-Enhancer-<version>-setup.exe` — a per-user installer (about 123 MB). This is the only file a user needs.

**For the person installing it**

1. Download the exe from the official link (a GitHub Release, not an email attachment).
2. Optionally verify it: `Get-FileHash .\Image-Enhancer-*-setup.exe -Algorithm SHA256` and compare with the checksum
   published beside the download.
3. Run it. It installs for the current user, so Windows does not ask for administrator rights.
4. Keep the default folder (`%LOCALAPPDATA%\Programs\Image Enhancer`) or choose another one, then finish.
5. Launch **Image Enhancer** from the Start menu or the desktop shortcut.

Until the build is signed, SmartScreen shows “Windows protected your PC”: choose **More info → Run anyway**. Do not
turn SmartScreen off system-wide. Uninstall from **Settings → Apps → Installed apps → Image Enhancer**, or from the
Start-menu folder.

**For the publisher**

- Publish the exe as a **GitHub Release** asset and link to that page. CI artifacts are handy for testing but expire.
- Publish a SHA-256 checksum beside the download.
- Sign the build with an Authenticode certificate: set `CSC_LINK` (a `.pfx` file or its base64) and
  `CSC_KEY_PASSWORD` before `pnpm dist`. An EV certificate earns SmartScreen reputation immediately; an OV one earns
  it over time.
- Test install and uninstall on a clean Windows VM before a wide release.
- There is no auto-update: each release is a new download. Installing a newer setup over an older one replaces the
  app and keeps the user's data. The build still uses Electron's default icon.

## How it works

1. **Import** an image, choose a category (or let Auto-detect suggest one), a prompt and a tile grid.
2. **Run**: tiles go to the provider one at a time (Safe) or two at a time (Normal), with pauses between them. A captcha,
   a logged-out session or a usage limit pauses the job and the provider window comes forward; solve it and the job
   carries on without repeating finished tiles.
3. **Result**: compare original and enhanced, check seams, fix flagged tiles (try again, accept, change prompt or picture).
4. **Save** as PNG, JPEG or WebP. If the provider returns tiles larger than they were sent, the result is larger than
   the original (up to 4x, capped at 72 megapixels) and keeps that detail.

## Data locations

Everything is in the app's data folder (**Settings -> Open data folder**; on Windows `%APPDATA%\@ie\desktop`):

| Path | Contents |
|---|---|
| `jobs.sqlite` | Jobs, tiles, events |
| `jobs/<id>/` | Tiles, provider outputs, the stitched picture |
| `overrides/<category>.json` | Your prompt-template edits (the shipped catalog is never modified) |
| `settings.json` | Pacing preset, watch mode, acknowledgements |
| `Partitions/` | Provider logins (browser storage) |

Nothing is deleted automatically. **Settings -> Clear job data** removes all jobs after a confirmation.
